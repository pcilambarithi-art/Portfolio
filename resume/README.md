# Resume Directory

Place your official resume PDF here named:
`resume.pdf`

Once placed at `public/resume/resume.pdf`:
1. The "Download Resume" button in the Hero section and Navigation will automatically detect and link to it.
2. Clicking it opens the PDF in a new browser tab for clean viewing and downloading.
3. If no file is placed here, the UI gracefully presents an info modal notifying the visitor that the resume is available upon request via email (`ilambarithi2006@gmail.com`).
